# JP-POWER Official

Official frontend store for **JP-POWER** — Japan Technology badminton equipment.

## Tech
- Pure HTML / CSS / JS (no framework)
- Deployed on Cloudflare Pages: https://jppowerofficial.pages.dev

## Structure
```
├── index.html
├── css/style.css
├── js/main.js
└── assets/   # logos, banners, product images
```

## Local
Open `index.html` directly in a browser, or serve:
```
npx serve .
```
